MEDFLOW
MedFlow is a hospital appointment and electronic medical records management system developed using springboot.

Features:
-User authentication
-Patient management
-Appointment scheduling
-Electronic medical reports
-Laboratory module
-Pharmacy module
-Reports & analytics

Stack:
-Java
-Springboot
-Spring security
-Spring Data JPA
-Thymeleaf
-MySQL
-Bootstrap
